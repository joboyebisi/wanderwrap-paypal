PayPal trust boundary

Money moves only when verified application state allows it

Contribution flow Working

  1. Log in with PayPal links the Sandbox identity.
  2. Orders v2 creates an idempotent contribution order.
  3. The member approves payment on PayPal.
  4. Server capture and signed webhook reconciliation update DynamoDB.
  5. The group receives aggregate progress without private amounts.

Recipient payout Fail closed

  1. Verified target unlocks the organiser's reveal action.
  2. SES delivers a private 30-day claim link.
  3. The recipient unwraps the gift and reads real messages.
  4. Payout stays blocked while the app lacks PayPal Payouts scope.
  5. Future item webhooks, not a redirect, will confirm success.
