# Contributing to WanderWrap

Keep changes focused on making group gifting more thoughtful, safe and effortless.

1. Create a focused branch.
2. Never use real payment credentials or personal group-chat data in fixtures.
3. Preserve explicit approval gates around analysis, payments, purchases, payouts and dispatch.
4. Run `npm run check`, `npm run build` and `npm audit`.
5. Describe user-visible behaviour and relevant sandbox testing in the pull request.

Agent prompt changes should include at least one positive case, one ambiguity case and one safety/adversarial case in the pull request notes.
